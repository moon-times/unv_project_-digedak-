# 화면 목업 디자인 정리

`딕으닥 화면 목업.html`을 브라우저로 열어 보며 색, 글꼴, 모양, 화면 구성을 정리한 문서입니다. 목업 파일은 압축된 단일 HTML이라 코드로 읽기 어려우니, 구현할 때는 이 문서의 값을 쓰고 모양은 목업을 열어 확인하세요.

- 목업은 아직 미리보기 단계입니다. 기능과 동작의 기준은 `docs/01_project_overview.md`이고, 목업과 다르게 정한 것은 아래 [목업과 다르게 가는 점](#목업과-다르게-가는-점)에 적습니다.
- 목업에는 화면 9개가 1440 × 810 크기로 세로로 이어져 있습니다: 랜딩, 로그인·회원가입, 내 프로젝트, 스튜디오 ①~④, 내보내기 팝업(회원·게스트).
- 값은 목업에서 계산된 스타일을 그대로 뽑은 것입니다.

## 분위기

- 따뜻한 크림색과 갈색 바탕에, 진한 갈색 테두리와 글자를 씁니다. 흰색과 회색은 거의 쓰지 않습니다.
- 테두리는 2px 진갈색 실선이고, 그림자는 흐림 없이 아래로만 3~4px 떨어집니다. 손으로 그린 스티커 같은 느낌입니다.
- 버튼은 대부분 알약 모양(완전히 둥근 모서리)이고, 주요 버튼은 진초록으로 채웁니다.
- 제목과 숫자는 동글동글한 Jua 글꼴, 본문은 IBM Plex Sans KR입니다.
- 랜딩과 로그인 화면에는 헤드폰을 쓰고 땅에서 고개를 내민 마스코트가 나옵니다(`딕으닥_아이콘.png`와 같은 캐릭터).
- 스튜디오 타임라인만 어두운 갈색 바탕이고, 트랙마다 파스텔 색 음표 블록이 올라갑니다.

## 모양

- **테두리**: 버튼, 카드, 패널, 타임라인 모두 2px `ink` 실선이 기본입니다. 음표 블록은 1px.
- **모서리**: 버튼·탭·칩 `999px`(알약), 번호 원·재생 버튼 `50%`, 카드·안내 상자 `12~14px`, 타임라인 `20px`, 작은 태그 `5px`, 음표 블록 `2~3px`.
- **그림자**: 흐림 없는 아래 그림자만 씁니다. 작은 버튼 `0 3px 0 #2B2018`, 큰 버튼 `0 4px 0 #2B2018`, 팝업 `0 8px 0 #2B2018`.
- **크기**: 누르는 요소는 높이 44px 이상(헤더 버튼 44px, 다음 단계 버튼 52px, 재생·정지 버튼 46px 원).
- **"확장" 표시**: 기본 범위 밖이라 나중에 할 기능은 점선 테두리(`line-dashed`) 버튼이나 작은 "확장" 태그로 표시합니다.

## 화면 구성

### 랜딩 `/`

- 위: 로고(마스코트 + "딕으닥"), 오른쪽에 [로그인]
- 가운데 왼쪽: 큰 제목 "흥얼거림을 밴드곡으로", 한 줄 설명, [바로 만들어보기](진초록), [로그인], "설치도 회원가입도 없이 바로 녹음할 수 있어요. 저장할 때만 로그인하면 돼요."
- 가운데 오른쪽: 헤드폰 쓴 마스코트 그림
- 아래 진갈색 띠: 3단계 소개 카드(① 흥얼거리기, ② 음표 고치기, ③ 반주 붙이기)와 작은 그림, 맨 아래에 저작권과 "데스크톱 Chrome에서 가장 잘 동작해요"

### 로그인 · 회원가입

- 왼쪽 반: 진갈색 면에 "게스트로 만든 곡도 그대로 이어져요"와 설명, 아래에 마스코트
- 오른쪽 반: [로그인 | 회원가입] 탭, "다시 오셨네요", 이메일·비밀번호, "비밀번호를 잊었나요?", [로그인], "또는", [GitHub로 계속하기], [Google로 계속하기], "로그인 없이 먼저 해 보고 싶다면 게스트로 만들어보기"

### 내 프로젝트 `/projects`

- 위: 로고, "내 프로젝트" 탭, 오른쪽에 아바타·이름·[로그아웃]
- 제목 "내 프로젝트"와 개수, 오른쪽에 [+ 새 프로젝트]
- 카드 4열: 미니 피아노롤 썸네일(어두운 바탕에 초록 음표), 곡 제목, 키·장르·BPM 태그, "오늘 10:42 수정", 오른쪽 아래 둥근 재생 버튼, `···` 메뉴(열기 / 공유 링크 만들기 `확장` / 삭제)

### 내보내기 팝업

화면 위에 어두운 막(`rgba(43, 32, 24, 0.55)`)을 깔고 가운데에 `surface` 상자를 띄웁니다.

- 회원: "내보내기" 제목과 닫기(×), 곡 제목 입력, "WAV 파일" 상자(멜로디와 반주(드럼 · 베이스 · 건반 · 기타) 5트랙을 하나로 합친다는 설명과 길이, [⬇ WAV 다운로드], 진행률 막대 "WAV로 만드는 중 64%"), "프로젝트는 자동 저장돼요. 마지막 저장 10:42", "WAV를 내 프로젝트에도 보관하기" `확장`
- 게스트: "로그인하면 바로 저장할 수 있어요", WAV 다운로드와 저장은 회원 기능이고 로그인해도 작업이 이어진다는 설명, [로그인하고 저장하기], [계속 편집하기]
- 모양(2026-11-13 정함): 삭제 확인 창과 같은 `<dialog>` 틀(`surface`, 2px `ink`, 막 `ink/55`)에 그림자 `0 8px 0 ink`
  - 진행률: `paper` 바탕 알약 막대에 `primary` 채움, 옆에 "WAV로 만드는 중 64%"
  - 실패: `danger` 글자 안내 + [다시 시도](보조 버튼)
  - `확장` 표시는 코드에서 "준비 중" 태그(`src/app/_components/Soon.tsx`)로 씁니다

## 목업과 다르게 가는 점

팀에서 정했거나 구현하면서 바꾼 점입니다. 새로 정하면 여기에 추가하세요.

- **진행 바 단계 열림**: 목업은 모든 단계를 누를 수 있는 모양이지만, 앞 단계 결과가 있어야 다음 단계가 열립니다(녹음 → 멜로디가 있으면 보정 → 코드가 있으면 반주 → 반주가 있으면 믹싱). 열린 단계끼리는 자유롭게 오갑니다. 끝난 단계 체크도 "다음 단계가 열렸는가"로 판단합니다.
- **BPM 바꾸는 곳**: ① 녹음 패널(A)의 입력과 ③ 반주 패널(B)의 슬라이더에서 바꿉니다. 둘 다 store의 `setBpm`을 씁니다. 재생 바는 표시만 합니다.

## 코드 적용 상태

- 스튜디오 공통 틀(헤더, 진행 바, 다음 단계 버튼, 재생 바)은 목업 구조와 문구에 맞췄습니다.
- 색 토큰과 글꼴이 `src/app/globals.css` · `src/app/layout.tsx`에 들어갔습니다. 위 색 표의 이름 그대로 Tailwind 클래스로 씁니다: `bg-paper`, `bg-surface`, `text-ink`, `text-ink-muted`, `border-line`, `border-line-dashed`, `bg-primary`, `text-on-primary`, `bg-earth`, `bg-record`, `text-danger`.
- 글꼴: 본문은 기본(`font-sans` = IBM Plex Sans KR), 제목 · 숫자는 `font-display`(Jua).
- 다크 모드는 없습니다. 키보드 포커스는 모든 요소에 2px `primary` 외곽선이 공통으로 붙습니다.
- 새 코드는 `#2B2018` 같은 값 대신 토큰을 쓰세요. 예전 이름 `foreground` · `background`는 지웠습니다.
- 타임라인 · 트랙 토큰: `bg-timeline`, `bg-timeline-row`, `from-timeline-ruler-from to-timeline-ruler-to`, `text-timeline-text`, `border-timeline-grid`, 트랙은 `track-{chord|melody|bass|keys|guitar}-{from|to|border}`(코드는 테두리 없이 `ink`), 드럼은 `track-drum` · `track-drum-low`(킥) · `track-drum-high`(하이햇 · 크래시). 믹서 점은 각 트랙의 `-to` 색(드럼은 `track-drum`)
